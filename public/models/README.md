# Human-model source

The requested model is [Joe | Realistic Human 3D Model](https://sketchfab.com/3d-models/joe-realistic-human-3d-model-2a108401fe5547409a3ad666b9b7d6b3)
by [Arjun P Krishna](https://sketchfab.com/arjunpkrishna), licensed under
[Creative Commons Attribution 4.0](https://creativecommons.org/licenses/by/4.0/).

Sketchfab's public metadata confirms that it is downloadable, but its official
download API requires authentication (HTTP 401 without a signed-in account).
**The Joe model is not included in this repository.** The app does not scrape
Sketchfab's viewer assets or substitute a different asset under that name.

Download the model using Sketchfab's normal signed-in download flow, then use
**Human model → Import a GLB or glTF ZIP**. The importer loads the real geometry,
embedded or ZIP-local textures, Draco, and Meshopt compression; normalizes the
display height; and preserves the original pose and PBR materials.

The default form and garment templates are generated by this app. They are not
photogrammetry scans, cloth simulation, or an exact fit for arbitrary body meshes.
Imported assets remain local to the current tab. Enable the Joe credit when using
that model; the displayed credit links to the source, author, and license.
